# 🛡️ DevGuard 4.0 | Severiche Architecture

**DevGuard 4.0** es un sistema inteligente de cotización diseñado para desarrolladores independientes que buscan profesionalizar su proceso de ventas. Esta herramienta no solo calcula costos basados en horas y complejidad, sino que genera propuestas técnicas de alta gama listas para enviar por PDF o WhatsApp.

![Tech](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react)
![Tech](https://img.shields.io/badge/Tailwind_v4-38B2AC?style=for-the-badge&logo=tailwind-css)

## Características Principales
- **Estética Severiche Gold:** Interfaz premium con modo oscuro profundo y efectos de glassmorphism.
- **Cálculo Inteligente:** Lógica avanzada de multiplicadores para proyectos "desde cero" o de alta urgencia.
- **Generador de PDF:** Exportación de propuestas técnicas con cláusulas de calidad y anticipo del 40%.
- **Venta en un Click:** Integración directa con la API de WhatsApp para envío de resúmenes inmediatos.
- **Persistencia Local:** Historial de proyectos guardado localmente mediante LocalStorage.

## Stack Tecnológico
- **Frontend:** React.js (Vite)
- **Estilos:** Tailwind CSS v4 (Configuración mediante `@theme`)
- **Documentación:** jsPDF & jsPDF-AutoTable
- **Fuentes:** Inter & Fira Code
